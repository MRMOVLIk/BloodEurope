BLOODY EUROPE - проект Android-приложения
==========================================

Это готовый проект: игра открывается внутри приложения на весь экран, без интернета.
Иконка и название "Bloody Europe" уже настроены. APK из этого проекта я сам собрать не мог
(в моём окружении нет средств сборки Android), поэтому проект не проверялся сборкой.
Если сборка выдаст ошибку, пришли мне её текст, и я поправлю.

СПОСОБ 1. Через GitHub с телефона (бесплатно, ПК не нужен)
1. Зарегистрируйся на github.com и создай новый репозиторий (Public).
2. Загрузи в него все файлы и папки из этого архива (Add file -> Upload files).
   Папка .github скрытая: если телефон её не показывает, создай файл вручную:
   Add file -> Create new file, в имени введи  .github/workflows/build-apk.yml
   и вставь туда содержимое файла build-apk.yml из архива.
3. Открой вкладку Actions -> Build APK -> Run workflow.
4. Через 3-5 минут открой готовый запуск, внизу в Artifacts скачай BloodyEurope-apk.
   Внутри будет app-debug.apk. Установи его (разреши установку из неизвестных источников).

СПОСОБ 2. Android Studio на компьютере (когда починишь ПК)
1. Открой папку проекта в Android Studio.
2. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
3. APK появится в app/build/outputs/apk/debug/.

СПОСОБ 3. Онлайн-конвертер "сайт в APK"
Загрузи файл BloodyEurope.html (лежит отдельно) и иконку bloody-europe-icon-512.png
в любой сервис "HTML to APK". Какой сервис выбрать и как он сейчас работает, я не проверял.

Где менять игру: app/src/main/assets/index.html
Название приложения: app/src/main/res/values/strings.xml
Иконки: app/src/main/res/mipmap-*/
